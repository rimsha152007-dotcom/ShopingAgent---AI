# ShopingAgent---AI
An AI-driven customer service shopping assistant.
Agent integrated in system that update order adrress, cancel order, through tolls rather than direct access to database

## Tech Stack
- **Backend:** FastAPI, Python, SQLAlchemy, PostgreSQL
- **LLM Integration:** Groq, Gemini, Ollama
- **Frontend:** React, Vite
- **Infrastructure:** Docker, GitHub Actions
